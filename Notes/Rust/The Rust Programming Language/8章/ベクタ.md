## ベクタの生成

空のベクタを新たに作るには、以下のように`Vec::new`関数を呼ぶ

```Rust
let v: Vec<i32> = Vec::new();
```

- `Vec<i32>`のように、ベクタが保持する要素の型を指定する必要がある

```Rust
let v = vec![1, 2, 3];
```

- `vec!`マクロを使うと、要素を指定してベクタを生成できる
- この場合、要素の型はコンパイラが推論する

## ベクタの更新

```rust
let mut v = Vec::new();

v.push(5);
v.push(6);
v.push(7);
v.push(8);
```

- どのような変数でも、変更するには`mut`を付ける必要がある（[[Notes/Rust/The Rust Programming Language/3章/変数と可変性|変数と可変性]]）
- `push`メソッドを使うと、ベクタの末尾に要素を追加できる
- 中に入れる要素の型は、最初に追加した要素の型に基づいて決まる

## ベクタのドロップ

```rust
{
    let v = vec![1, 2, 3, 4];
}
// vはここでスコープ外になり、ドロップされる
```

- ベクタがスコープ外になると、そのベクタと中のすべての要素がドロップされる

## ベクタの要素を読む

```rust
let v = vec![1, 2, 3, 4, 5];

let third: &i32 = &v[2];
println!("The third elements is {}", third);

match v.get(2) {
    Some(third) => println!("The third element is {}", third),
    None => println!("There is no third element"),
}
```

- ベクタの要素にアクセスするには、インデックスを使う方法と`get`メソッドを使う方法がある
- インデックスを使うと、要素が存在しない場合にパニックが発生する
- `get`メソッドは、要素が存在しない場合に`None`を返すので、安全にアクセスできる

## ベクタ内の値を順に変更する

```rust
let v = vec![100, 32, 57];
for i in &v {
    println!{"{}", i};
}
```

- `for`ループを使って、ベクタ内の各要素に順にアクセスできる
- この場合、`&v`を使ってベクタへの参照を渡しているため、ベクタの所有権は移動しない

## `Enum`を使って複数の型を保持する

```rust
enum SpreadsheetCell {
    Int(i32),
    Float(f64),
    Text(String),
}

let row = vec![
    SpreadsheetCell::Int(3),
    SpreadsheetCell::Text(String::from("blue")),
    SpreadsheetCell::Float(10.12),
];
```

- ベクタは同じ型の要素しか保持できないが、`enum`を使うことで複数の型を保持できる
- 上記の例では、`SpreadsheetCell`という`enum`を定義し、異なる型の値を保持できるようにしている
- ベクタ`row`は、`SpreadsheetCell`型の要素を保持している
