## ベクタの生成

空のベクタを新たに作るには、以下のように`Vec::new`関数を呼ぶ

```Rust
let v: Vec<i32> = Vec::new();
```

- `Vec<i32>`のように、ベクタが保持する要素の型を指定する必要がある

```Rust
let v = vec![1, 2, 3];
```

- `vec!`マクロを使うと、要素を指定してベクタを生成できる
- この場合、要素の型はコンパイラが推論する

## ベクタの更新

```rust
let mut v = Vec::new();

v.push(5);
v.push(6);
v.push(7);
v.push(8);
```

- どのような変数でも、変更するには`mut`を付ける必要がある（[[Notes/Rust/The Rust Programming Language/3章/変数と可変性|変数と可変性]]）
- `push`メソッドを使うと、ベクタの末尾に要素を追加できる
- 中に入れる要素の型は、最初に追加した要素の型に基づいて決まる

## ベクタのドロップ

```rust
{
    let v = vec![1, 2, 3, 4];
}
// vはここでスコープ外になり、ドロップされる
```
