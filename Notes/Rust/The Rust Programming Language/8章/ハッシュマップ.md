## 新規ハッシュマップを生成する

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();

scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Yellow"), 50);
```

- `HashMap::new`関数は空のハッシュマップを生成する
- `insert`メソッドは、キーと値のペアをハッシュマップに追加する
- キーと値の型は、ハッシュマップが最初に使用されたときに決定される
- `use`宣言は、`HashMap`型をスコープに持ち込むために必要である

```rust
use std::collections::HashMap;

let teams = vec![String::from("Blue"), String::from("Yellow")];
let initial_scores = vec![10, 50];

let scores: HashMap<_, _> = teams.iter().zip(initial_scores.iter()).collect();
```

- `collect`メソッドは、イテレータからコレクションを生成するために使用される
- `zip`メソッドは、2 つのイテレータを組み合わせてタプルのイテレータを生成する
- `HashMap<_, _>`の型注釈は、コンパイラにハッシュマップのキーと値の型を推論させるために使用される

## ハッシュマップと所有権

```rust
use std::collections::HashMap;

let field_name = String::from("Favorite color");
let field_value = String::from("Blue");

let mut map = HashMap::new();
map.insert(field_name, field_value);
```

- ハッシュマップに値を挿入すると、キーと値の所有権がハッシュマップに移動する
- そのため、挿入後に元の変数を使用しようとするとコンパイルエラーになる
