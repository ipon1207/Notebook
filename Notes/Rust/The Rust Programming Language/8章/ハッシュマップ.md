## 新規ハッシュマップを生成する

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();

scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Yellow"), 50);
```

- `HashMap::new`関数は空のハッシュマップを生成する
- `insert`メソッドは、キーと値のペアをハッシュマップに追加する
- キーと値の型は、ハッシュマップが最初に使用されたときに決定される
- `use`宣言は、`HashMap`型をスコープに持ち込むために必要である

```rust
use std::collections::HashMap;

let teams = vec![String::from("Blue"), String::from("Yellow")];
let initial_scores = vec![10, 50];

let scores: HashMap<_, _> = teams.iter().zip(initial_scores.iter()).collect();
```

- `collect`メソッドは、イテレータからコレクションを生成するために使用される
- `zip`メソッドは、2 つのイテレータを組み合わせてタプルのイテレータを生成する
- `HashMap<_, _>`の型注釈は、コンパイラにハッシュマップのキーと値の型を推論させるために使用される

## ハッシュマップと所有権

```rust
use std::collections::HashMap;

let field_name = String::from("Favorite color");
let field_value = String::from("Blue");

let mut map = HashMap::new();
map.insert(field_name, field_value);
```

- ハッシュマップに値を挿入すると、キーと値の所有権がハッシュマップに移動する
- そのため、挿入後に元の変数を使用しようとするとコンパイルエラーになる

## ハッシュマップの値にアクセスする

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();

scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Yellow"), 50);

let team_name = String::from("Blue");
let score = score.get(&team_name);
```

- `score`は`"Blue"`をキーと紐づいた値になり、`Some(&10)`となる
- `get`で`Option<&V>`を返すため、`Some`で結果が包まれる
- キーに対応する値がハッシュマップになければ、`get`は`None`になる

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();

scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Yellow"), 50);

for (key, value) in &scores {
    println!("{}: {}", key, value);
}
```

- `for`ループでハッシュマップのキーと値のペアを走査することができる

## ハッシュマップを更新する

### 値を上書きする

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();

scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Blue"), 10);

println!("{:?}", scores);
```

- ハッシュマップには 1 つのキーと値の組しか含まれない
- このコードにおいては`{"Blue": 26}`と出力される（`10`は上書きされる）

### キーに値がなかった時のみ値を挿入する

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert(String::from("Blue"), 10);

scores.entry(String::from("Yellow")).or_insert(50);
scores.entry(String::from("Blue")).or_insert(50);

println!("{:?}", scores);
```

- `entry`メソッドは引数としてチェックしたいキーを取り、戻り値として`Entry`という enum を返す
- `Entry`は値が存在するかしないかを示す
- `or_insert`メソッドは、対応する`Entry`キーが存在したときにそのキーに対する値への可変参照を返すために定義されている
- `or_insert`メソッドで値が存在しなければ、引数をそのキーの新しい値として挿入し、新しい値への可変参照を返す
