## メソッドを定義する

```Rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

fn main() {
    let rect1 = Rectangle { width: 30, height: 50 };

    println!(
        "The area of the rectangle is {} square pixels.",
        rect1.area()
    );
}
```

- `impl`キーワードを使用して、構造体に関連するメソッドを定義
- `&self`はメソッドが呼び出されたインスタンスへの不変参照を表す
- 複数の `impl`ブロックを使用して、同じ構造体に対して異なるメソッドセットを定義できる

## 関連関数

```rust
impl Rectangle {
    fn square(size: u32) -> Rectangle {
        Rectangle { width: size, height: size }
    }
}
```

- 関連関数は特定のインスタンスに関連付けられていない関数
- `self`パラメータを持たない
- 構造体名を使用して呼び出す（例: `Rectangle::square(3)`）

参考(https://doc.rust-jp.rs/book-ja/ch05-03-method-syntax.html)
