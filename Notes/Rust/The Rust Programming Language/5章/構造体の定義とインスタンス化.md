## 構造体の定義

```rust
struct User {
    username: String,
    email: String,
    sign_int_count: u64,
    active: bool,
}
```

- `struct`キーワードで構造体を定義
- データの名前と型を定義したものを**フィールド**と呼ぶ

## 構造体のインスタンス化

```rust
let user1 = User {
    email: String::from("someone@example.com"),
    username: String::from("someusername123"),
    active: true,
    sign_int_count: 1,
}
```

- 構造体を定義した後、その構造体の**インスタンス**を作成できる
- 各フィールドに対して値を指定する
- 構造体名を記述し、`key: value`形式でフィールドに値を割り当てる
- フィールドの順序は定義時と異なってもよい

## インスタンスのフィールドへのアクセス

```rust
let mut user1 = User {
    email: String::from("someone@example.com"),
    username: String::from("someusername123"),
    active: true,
    sign_int_count: 1,
}

user1.email = String::from("newemail@example.com");
```

- ドット演算子（`.`）を使用して、インスタンスのフィールドにアクセスおよび変更が可能
- `mut`キーワードを使用して、インスタンス自体を可変にすることでフィールドの値を変更できる

## フィールド初期化省略記法

```rust
fn build_user(email: String, username: String) -> User {
    User {
        email,
        username,
        active: true,
        sign_in_count: 1,
    }
}
```

- 関数の引数名と構造体のフィールド名が同じ場合、省略記法を使用できる

## 構造体更新記法

```rust
let user2 = User {
    email: String::from("another@example.com"),
    username: String::from("anotherusername567"),
    ..user1
};
```

- 既存のインスタンスから新しいインスタンスを作成する際に便利
- `..`構文を使用して、既存のインスタンスから残りのフィールドをコピーできる
