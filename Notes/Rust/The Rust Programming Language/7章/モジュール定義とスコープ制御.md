## モジュール

```Rust
mod front_of_house {
    mod hosting {
        fn add_to_waitlist() {}

        fn seat_at_table() {}
    }

    mod serving {
        fn take_order() {}

        fn serve_order() {}

        fn take_payment() {}
    }
}
```

- モジュールは、`mod` キーワードで定義される
- モジュールには、関数、構造体、列挙型、定数、その他のモジュールを含めることができる
- モジュールは、コードを整理し、名前の衝突を防ぐために使用される
- モジュールは、階層的にネストできる

```PlainText
crate
 └── front_of_house
     ├── hosting
     │   ├── add_to_waitlist
     │   └── seat_at_table
     └── serving
         ├── take_order
         ├── serve_order
         └── take_payment
```
