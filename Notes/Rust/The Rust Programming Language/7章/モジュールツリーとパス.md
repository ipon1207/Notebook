```Rust
mod front_of_house {
    mod hosting {
        fn add_to_waitlist() {}
    }
}

pub fn eat_at_restaurant() {
    // Absolute path
    // 絶対パス
    crate::front_of_house::hosting::add_to_waitlist();

    // Relative path
    // 相対パス
    front_of_house::hosting::add_to_waitlist();
}
```

- モジュールにアクセスするには、絶対パスまたは相対パスを使用できる
- **絶対パス**は、クレートの名前か`crate`という文字列を使うことで、クレートルートからスタートする
- **相対パス**は、`self`、`super`または今のモジュール内の識別子を使うことで、現在のモジュールからスタートする
- `::`はモジュールツリー内の階層を区切るために使われる
- 相対パスと絶対パスの使い分けは、要素を定義するコードを、その要素を使うコードと別々に動かすか一緒に動かすかどうかで決めるのがよい

## パスを`pub`キーワードで公開する

```rust
mod front_of_house {
    pub mod hosting {
        fn add_to_waitlist() {}
    }
}

pub fn eat_at_restaurant() {
    // Absolute path
    // 絶対パス
    crate::front_of_house::hosting::add_to_waitlist();

    // Relative path
    // 相対パス
    front_of_house::hosting::add_to_waitlist();
}
```

- モジュールやその中の要素を他のモジュールからアクセス可能にするには、`pub`キーワードを使って公開する必要がある

## 相対パスを`super`で始める

```rust

fn serve_order() {}

mod back_of_house {
    fn fix_incorrect_order() {
        cook_order();
        super::serve_order();
    }

    fn cook_order() {}
}
```

- `super`キーワードは、親モジュールを参照するために使用される
- 上記の例では、`fix_incorrect_order`関数内で`super::serve_order()`を使用して、親モジュールにある`serve_order`関数にアクセスしている
