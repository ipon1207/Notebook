> [!IMPORTANT]
> Rust における値はすべてデータ型を持つ
> Rust のデータ型は主にスカラー型と複合型に分類される

## スカラー型

スカラー型は単一の値を表すデータ型で、以下の 4 つがある

- **整数**
- **浮動小数点数**
- **論理値**
- **文字**

### 整数型

| 大きさ    | 符号付き | 符号無し |
| --------- | -------- | -------- |
| 8 ビット  | i8       | u8       |
| 16 ビット | i16      | u16      |
| 32 ビット | i32      | u32      |
| 64 ビット | i64      | u64      |
| arch      | isize    | usize    |

- `isize` と `usize` はアーキテクチャに依存するサイズを持つ

**整数リテラル**

| 数値リテラル | 例          |
| ------------ | ----------- |
| 10 進数      | 98_222      |
| 16 進数      | 0xff        |
| 8 進数       | 0o77        |
| 2 進数       | 0b1111_0000 |
| バイト文字列 | b'A'        |

> [!NOTE]
> **何を使うか迷ったら i32 を使え**
