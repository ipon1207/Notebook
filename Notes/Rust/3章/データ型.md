> [!IMPORTANT]
> Rust における値はすべてデータ型を持つ
> Rust のデータ型は主にスカラー型と複合型に分類される

## スカラー型

スカラー型は単一の値を表すデータ型で、以下の 4 つがある

- **整数**
- **浮動小数点数**
- **論理値**
- **文字**

### 整数型

| 大きさ    | 符号付き | 符号無し |
| --------- | -------- | -------- |
| 8 ビット  | i8       | u8       |
| 16 ビット | i16      | u16      |
| 32 ビット | i32      | u32      |
| 64 ビット | i64      | u64      |
| arch      | isize    | usize    |

- `isize` と `usize` はアーキテクチャに依存するサイズを持つ

**整数リテラル**

| 数値リテラル | 例          |
| ------------ | ----------- |
| 10 進数      | 98_222      |
| 16 進数      | 0xff        |
| 8 進数       | 0o77        |
| 2 進数       | 0b1111_0000 |
| バイト文字列 | b'A'        |

> [!NOTE]
>
> ### 何を使うか迷ったら `i32` を使え

## 浮動小数点数型

Rust には 2 種類の浮動小数点数型がある

- `f32`：32 ビットの単精度浮動小数点数
- `f64`：64 ビットの倍精度浮動小数点数（デフォルト）

## 論理値型

論理値型は真偽値を表し、`true` または `false` のいずれかの値を取る

```Rust
fn main() {
    let t = true;

    let f: bool = false;
}
```

## 文字型

文字型は Unicode スカラー値を表し、シングルクォートで囲まれた 4 バイトの値を持つ

```Rust
fn main() {
    let c = 'z';
    let z: char = 'ℤ';
    let heart_eyed_cat = '😻';
}
```

## 複合型

複合型は複数の値を一つにまとめるデータ型で、以下の 2 つがある

- **タプル**
- **配列**
