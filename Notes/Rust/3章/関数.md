## 関数定義

```Rust
fn main() {
    println!("Hello, world!");

    another_function();
}

fn another_function() {
    println!("Another function.");  // 別の関数
}
```

**実行結果**

```bash
$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished dev [unoptimized + debuginfo] target(s) in 0.28s
     Running `target/debug/functions`
Hello, world!
Another function.
```

- `fn` キーワードを使って関数を定義する
- 関数名は小文字とアンダースコアで構成される（スネークケース）
- 関数の定義位置は自由

## 関数の引数

```Rust
fn main() {
    another_function(5);
}

fn another_function(x: i32) {
    println!("The value of x is: {}", x);   // xの値は{}です
}
```

**実行結果**

```bash
$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished dev [unoptimized + debuginfo] target(s) in 1.21s
     Running `target/debug/functions`
The value of x is: 5
```

- 関数に引数を渡すことができる
- **引数には型注釈が必要**
- 引数はカンマで区切って複数指定可能

## 関数の構造

- **文**: 何らかの動作をして値を返さない命令
- **式**: 結果値に評価される命令

```Rust
fn main() {
    let y = 6;
}
```

- `let y = 6;` は文（値を返さない）
- 関数定義も文である
- 全体的に文で構成される

```Rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };

    println!("The value of y is: {}", y);
}
```

**実行結果**

```bash
$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished dev [unoptimized + debuginfo] target(s) in 1.21s
     Running `target/debug/functions`
The value of y is: 4
```

- ブロック `{}` は式であり、ブロック内の最後の式がそのブロックの値となる
- `x + 1` はセミコロンがないため式として評価され、その結果が `y` に代入される

## 戻り値のある関数

```Rust
fn five() -> i32 {
    5
}

fn main() {
    let x = five();

    println!("The value of x is: {}", x);
}
```

**実行結果**

```bash
$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished dev [unoptimized + debuginfo] target(s) in 0.30s
     Running `target/debug/functions`
The value of x is: 5
```

- 関数の戻り値の型は `->` の後に指定する
- 戻り値は関数本体の最後の式で決まる（セミコロンを付けない）
- `return` キーワードを使って早期に値を返すことも可能
