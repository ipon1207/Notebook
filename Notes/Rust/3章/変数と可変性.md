```Rust
fn main() {
    let x = 5;
    println!("The value of x is: {}", x);     // xの値は{}です
    x = 6;
    println!("The value of x is: {}", x);
}
```

このコードをコンパイルすると以下のエラーが発生する


- このエラーは、変数 `x` が不変(immutable)であるため、再代入ができないことを示している
- Rust では、デフォルトで変数は不変であり、再代入を許可するには `mut` キーワードを使用して変数を可変(mutable)にする必要がある

```Rust
fn main() {
    let mut x = 5;
    println!("The value of x is: {}", x);
    x = 6;
    println!("The value of x is: {}", x);
}
```

## 変数と定数(constants)の違い

- 定数には `mut` キーワードを使用できない（常に不変）
- `const` キーワードを使用して宣言し、型注釈が必要
- 定数はグローバルスコープで宣言でき、関数内外で使用可能
- 定数式にしかセットできない（関数呼び出し結果や実行時に評価される値にはセットできない）
- 命名規則として、定数名はすべて大文字で、単語の区切りにアンダースコアを使用する

```Rust
const MAX_POINTS: u32 = 100_000;
```

## シャドーイング

```Rust
fn main() {
    let x = 5;

    let x = x + 1;

    {
        let x = x * 2;
        println!("The value of x in the inner scope is: {}", x);
    }

    println!("The value of x is: {}", x);
}
```

- このコードでは、同じ名前 `x` を使って複数回変数を宣言しているが、各宣言は新しい変数を作成している（シャドーイング）
- シャドーイングにより、元の変数を変更せずに新しい値を計算して保存できる
- シャドーイングは型の変更も可能（`mut` だと型の変更はできない）
