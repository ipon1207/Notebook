## `use std::io;`

標準入力を受け付け、標準出力に出力するためには `io` （入出力）ライブラリを使う必要がある
`io` ライブラリは `std` （標準ライブラリ）に含まれている

> [!NOTE]
> Rust はデフォルトで、標準ライブラリで定義されているものをいくつか自動的にインポートして、すべてのプログラムで使用できるようにしている(**Prelude**)
> Prelude に含まれないものは明示的にインポートする必要がある

## 値を変数に保持する

```Rust
let mut guess = String::new();
```

- Rust では変数はデフォルトで不変(immutable)であるため、値を変更する場合は `mut` キーワードを使って可変(mutable)にする必要がある

```Rust
let apples = 5; // 不変
let mut bananas = 10; // 可変
```

- `String::new()` によって `String` 型の新しいインスタンスを返し、それを `guess` 変数に束縛している
- `String` は標準ライブラリによって提供される文字列型で、可変長で、UTF-8 でエンコードされたテキストを格納できる

## ユーザの入力を受け取る

```Rust
io::stdin()
    .read_line(&mut guess)
```

- `use std::io;` を書かずにインポートしなくても、`std::io::stdin()` で呼び出せる
- `io::stdin()` は標準入力ハンドルを取得する関数
- `read_line(&mut guess)` は標準入力から 1 行読み取り、指定した引数(`&mut guess`)に格納するメソッド
- `&mut guess` は `guess` 変数への可変参照を意味する(参照もデフォルトでは不変)
