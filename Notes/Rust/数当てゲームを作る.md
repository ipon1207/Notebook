## `use std::io;`

標準入力を受け付け、標準出力に出力するためには `io` （入出力）ライブラリを使う必要がある
`io` ライブラリは `std` （標準ライブラリ）に含まれている

> [!NOTE]
> Rust はデフォルトで、標準ライブラリで定義されているものをいくつか自動的にインポートして、すべてのプログラムで使用できるようにしている(**Prelude**)
> Prelude に含まれないものは明示的にインポートする必要がある

## 値を変数に保持する

```Rust
let mut guess = String::new();
```

- Rust では変数はデフォルトで不変(immutable)であるため、値を変更する場合は `mut` キーワードを使って可変(mutable)にする必要がある

```Rust
let apples = 5; // 不変
let mut bananas = 10; // 可変
```
