## `use std::io;`

標準入力を受け付け、標準出力に出力するためには `io` （入出力）ライブラリを使う必要がある
`io` ライブラリは `std` （標準ライブラリ）に含まれている

> [!NOTE]
> Rust はデフォルトで、標準ライブラリで定義されているものをいくつか自動的にインポートして、すべてのプログラムで使用できるようにしている(**Prelude**)
> Prelude に含まれないものは明示的にインポートする必要がある

## 値を変数に保持する

```Rust
let mut guess = String::new();
```

- Rust では変数はデフォルトで不変(immutable)であるため、値を変更する場合は `mut` キーワードを使って可変(mutable)にする必要がある

```Rust
let apples = 5; // 不変
let mut bananas = 10; // 可変
```

- `String::new()` によって `String` 型の新しいインスタンスを返し、それを `guess` 変数に束縛している
- `String` は標準ライブラリによって提供される文字列型で、可変長で、UTF-8 でエンコードされたテキストを格納できる

## ユーザの入力を受け取る

```Rust
io::stdin()
    .read_line(&mut guess)
```

- `use std::io;` を書かずにインポートしなくても、`std::io::stdin()` で呼び出せる
- `io::stdin()` は標準入力ハンドルを取得する関数
- `read_line(&mut guess)` は標準入力から 1 行読み取り、指定した引数(`&mut guess`)に格納するメソッド
- `&mut guess` は `guess` 変数への可変参照を意味する(参照もデフォルトでは不変)

## `Result` 型で失敗の可能性を扱う

```Rust
    .expect("Failed to read line");
```

- `read_line` メソッドは引数には標準入力の内容を格納し、返り値として `Result` 型を返す
- `Result` 型は**列挙型**(enum)であり、取りうる値として決まった数の**列挙子**(variants)を持つ
- 列挙型は`match` とよく使われる
- `Result` の列挙子は `Ok` と `Err` の 2 つ(処理が成功した場合と失敗した場合)
- `expect` メソッドは `Result` 型に対して呼び出され、`Ok` の場合は中身の値を返し、`Err` の場合はプログラムをクラッシュさせて指定したメッセージを表示する
- `expect` メソッドを記述しないでコンパイルしようとするとエラーが発生する

## `println!` マクロのプレースホルダー

```Rust
    println!("You guessed: {}", guess);
```

- `{}` は**プレースホルダー**と呼ばれ、後続の引数で指定された値で置き換えられる

> [!NOTE]
>
> ### クレートを使用して機能を追加する
>
> Rust では、標準ライブラリ以外にも**クレート**(crate)と呼ばれる外部ライブラリを使用して機能を追加できる
>
> - クレートは Cargo を使って管理され、`Cargo.toml` ファイルに依存関係として追加される
> - `cargo build` コマンドを実行すると、Cargo は依存関係のクレートをダウンロードしてビルドし、プロジェクトにリンクする
> - 一度ビルドすると、`Cargo.toml` の差分を読み取るため、再ビルドしても再度ダウンロードすることはない
>   `Cargo.lock` ファイルには、プロジェクトで使用されているすべてのクレートの正確なバージョンが記録される
>
> ### クレートを更新して新バージョンを取得する
>
> `cargo update` コマンドを実行すると、`Cargo.toml` に記載されたバージョン要件に基づいて、依存関係のクレートを最新バージョンに更新できる

## 乱数を生成する

```Rust
use rand::Rng;
use std::io;

fn main() {
    println!("Guess the number!");

    let secret_number = rand::rng().random_range(1..101); // rand::thread_rng().gen_range(1..101);

    println!("The secret number is: {}", secret_number);
    println!("Please input your guess.");

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

    println!("You guessed: {}", guess);
}
```

> [!WARNING]
> 上記のコードにおいて、`rand` クレートのバージョンが上がったため、`rand::thread_rng().gen_range(1..101);` の部分が `rand::rng().random_range(1..101);` に変更された。

- `rand` クレートは Rust で乱数を生成するための外部ライブラリ
- `use rand::Rng;` によって `Rng` トレイトをインポートしている
- `rand::rng()` 関数はスレッド固有の乱数生成器を返す
- `random_range(1..101)` メソッドは指定した範囲内（範囲式）で乱数を生成する
- `1..101` は `開始..終了` の範囲式で、開始値は含まれ、終了値は含まれないため、1 から 100 までの乱数が生成される（`..=` を使うと終了値も含まれる）

## 予想と秘密の数を比較する

```Rust
use rand::Rng;
use std::cmp::Ordering;
use std::io;

fn main() {
    // --snip--

    println!("You guessed: {}", guess);

    match guess.cmp(&secret_number) {
        Ordering::Less => println!("Too small!"),
        Ordering::Greater => println!("Too big!"),
        Ordering::Equal => println!("You win!"),
    }
}
```

- `use std::cmp::Ordering;` によって `Ordering` 列挙型をインポートしている
- `Ordering` 列挙型は 3 つの列挙子を持つ: `Less` (小さい), `Greater` (大きい), `Equal` (等しい)
- `cmp` メソッドは 2 つの値を比較し、`Ordering` 型の結果を返す
- `match` 式は `cmp` メソッドの返り値に基づいて異なるコードブロックを実行する
- `guess` と `secret_number` は型が違うためコンパイルエラーになる

```Rust
    // --snip--

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

    let guess: u32 = guess.trim().parse()
        .expect("Please type a number!");

    println!("You guessed: {}", guess);

    match guess.cmp(&secret_number) {
        Ordering::Less => println!("Too small!"),
        Ordering::Greater => println!("Too big!"),
        Ordering::Equal => println!("You win!"),
    }
```
