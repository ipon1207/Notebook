## Block Builder（ブロック組み立て）

- ユーザーが操作する UI 層
- **役割**: ドロップされたブロックから「構文木(AST)」のような構造データを作る $\rightarrow$ `node-sql-parser` を使えばよさそう
- **機能**: バリデーションをここで吸収する

## Query Parser & Planner（解析と計画）

- 入力された SQL を「**アニメーションの脚本(Step)**」に分解するロジック
- **入力**: `SELECT name FROM users WHERE age >= 20`
- **出力**:
  1. `Step: FROM` $\rightarrow$ `users` テーブルの全データをロードして表示
  2. `Step: WHERE` $\rightarrow$ `age >= 20` の条件評価（False の行を赤くハイライト $\rightarrow$ フェードアウト）
  3. `Step: SELECT` $\rightarrow$ `name` 以外のカラムをグレーアウト $\rightarrow$ 削除にするアニメーション表示

## Animation Engine（可視化レンダラー）

- `Framer Motion` を使って、Planner が作った「脚本」に従って DOM（テーブルや行や列）を動かすコンポーネント
- ユーザーは「再生」「一時停止」「ステップ送り」などができるようにする
