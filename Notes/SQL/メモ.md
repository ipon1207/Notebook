## アプリケーションのターゲット

1. **SQL の初学者がメインのターゲット**
2. **次に、SQL の学習でつまずいた経験のある人がサブターゲット**

## `sqlSimulator.ts`の改善内容

- ロジックの切り分け: 今後の拡張や保守を容易にするため、SQL の解析、実行、結果の生成などのロジックをモジュール化する

## 技術スタック

言語は変えないが、フロントエンド、バックエンド、データベース、インフラなどそれぞれ個々の技術スタックを見直す（Next.js はやめたい）

### AI 提案スタック

- フロントエンド: Vite + React (SPA)
- 状態管理: TanStack Query + Zustand
- バックエンド: Hono (Cloudflare Workers / Node.js)
- データベース: Supabase (PostgreSQL + Auth)
- インフラ：Cloudflare Pages / Vercel
