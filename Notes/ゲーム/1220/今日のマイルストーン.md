## 【灰色の箱庭で動くプロトタイプ】

1. 背景はただの立方体（グレーの箱）でいい
2. プレイヤーキャラを表示
3. **「ジャンプ」「攻撃」「回避」の手触りだけ**を作る
4. 敵（動かない箱）を攻撃して、破壊できる

## アクションの挙動

### ジャンプと移動の慣性（空中制御）

- [ ] 走りだしや停止に少し「滑る」感覚がある
- [ ] 空中で移動方向を変えられるが、慣性が働くので急に止まれない
- [ ] ボタンを離せばピタッと止まる（空中でも自由自在に方向転換できる）

### 「パリィ」の発動ロジック

- [ ] 防御ボタンを「**敵の攻撃が当たる直前**」に押すと成功
- [ ] 失敗しても「通常のガード」になる（リスクが低い）
- [ ] 防御ボタンではなく、**「攻撃」や「前進」などの特定のアクション**ををタイミングよく合わせる（
- [ ] 失敗すると直撃を食らう（ハイリスク・ハイリターン）

### ヒットストップと「吹っ飛び」

2D アクションの手ごたえ（殴った感）を作るのは、エフェクトではなく「**時間の停止（ヒットストップ）**」

- [ ] 攻撃が当たった瞬快、画面全体の動きを**0.1~0.3 秒程度**停止させる
- [ ] 敵が吹っ飛ぶアニメーションをつける

### キャラ切り替え（チェンジ）の挙動

- [ ] ボタンを押すと、今のキャラが消えて、同じ位置に次のキャラが出る
- [ ] ボタンを押すと、「**攻撃しながら**」次のキャラが飛び込んでくる
- [ ] 前のキャラが攻撃動作を終えるまで画面に残る
