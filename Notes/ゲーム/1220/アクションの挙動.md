## アクションの挙動

### ジャンプと移動の慣性（空中制御）

- [ ] 走りだしや停止に少し「滑る」感覚がある
- [ ] 空中で移動方向を変えられるが、慣性が働くので急に止まれない
- [ ] ボタンを離せばピタッと止まる（空中でも自由自在に方向転換できる）
- [x] 少し慣性はあるが、空中で制御しやすい

### 「パリィ」の発動ロジック

- [ ] 防御ボタンを「**敵の攻撃が当たる直前**」に押すと成功
- [ ] 失敗しても「通常のガード」になる（リスクが低い）
- [x] 防御ボタンではなく、**「攻撃」や「前進」などの特定のアクション**をタイミングよく合わせる
- [ ] 失敗すると直撃を食らう（ハイリスク・ハイリターン）
- [x] 装備やキャラごとに「パリィのタイミング」が異なる

### ヒットストップと「吹っ飛び」

2D アクションの手ごたえ（殴った感）を作るのは、エフェクトではなく「**時間の停止（ヒットストップ）**」

- [x] 攻撃が当たった瞬快、画面全体の動きを**0.1~0.3 秒程度**停止させる
- [x] 敵が吹っ飛ぶアニメーションをつける

### キャラ切り替え（チェンジ）の挙動

- [ ] ボタンを押すと今のキャラが消えて、同じ位置に次のキャラが現れる
- [x] ボタンを押すと、「**攻撃しながら**」次のキャラが飛び込んでくる
- [x] 前のキャラが攻撃動作を終えるまで画面に残る

> [!IMPORTANT]
>
> 1. **コヨーテタイム(Coyote Time)**
>    足場から足を踏み外して空中に落ちた後でも、**数フレーム（0.1 秒くらい）だけはジャンプ入力を受け付ける**処理
>
> 2. **先行入力(Input Buffering)**
>    着地する「少し前」や、攻撃が終わる「少し前」にボタンを押しても、次のアクションを予約して受け付けてあげる処理
