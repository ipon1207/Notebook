入力を受け取るには `cin` と `>>` を使う

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a;

    // 変数 a に入力を受け取る
    cin >> a;

    cout << a * 10 << endl;
}
```

## 繋げて入力

`cout` と同様に `cin` も `>>` を繋げて入力を受け取ることができる

```cpp
#include <bits/stdc++.h>
using namespace std;

int main () {
    int a, b, c;

    cin >> a >> b >> c;
    cout << a * b * c << endl;
}
```

- 入力が複数ある場合は、スペースか改行で区切られていれば分解して入力してくれる
