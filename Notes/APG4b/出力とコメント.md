## プログラムの基本形

**特になにもしないプログラム**
```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
}
```

- `main` 関数: C++のプログラムはこの関数から始まる（基本的に `main` 関数の中でのみ処理を考えればよい）

## 出力

**「Hello, world!」を表示するプログラム**
```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
	cout << "Hello, world!" << endl;
}
```

**実行結果**
```PlainText
Hello, world!
```

### `cout`

- C++で文字列を出力するには **`cout`** を使う
- **C++プログラムで文字列を扱う場合、 `" "` で囲む必要がある**
- **`endl` は改行を示す**

## 複数の出力

```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
	cout << "a",
	cout << "b" << endl;
	cout << "c" << "d" << endl;
}
```

**実行結果**
```PlainText
ab
cd
```

- `cout << "c" << "d"` と書くことで、`cd` と出力できる（`cout` に対してそれぞれ前から流し込んでいるイメージ？）
## 数値の出力

```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
	cout << 2525 << endl;
}
```

**実行結果**
```PlainText
2525
```

## `#include <bits/stdc++.h>`

- C++の機能を「すべて」読み込むためのもの
- `cout` や `endl` は `include <iostream>` でも読み込むことができる
- 競技プログラミングなら特にパフォーマンスについて気にする必要ないからどんどん使おう！

## `using namespace std;`

- `cout` や `endl` は通常 `std::cout` や `std::endl` ようにする必要がある
- `using namespace std;` は `std::` を省略できる
- これも競技プログラミングにおいてはどんどん使っていけ
