## プログラムの基本形

**特になにもしないプログラム**
```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
}
```

- `main` 関数: C++のプログラムはこの関数から始まる（基本的に `main` 関数の中でのみ処理を考えればよい）

## 出力

**「Hello, world!」を表示するプログラム**
```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
	cout << "Hello, world!" << endl;
}
```

**実行結果**
```PlainText
Hello, world!
```
