## 文字列の長さ

文字列の長さ（文字数）は `文字列変数.size()` で取得できる

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string str = "Hello";
    cout << str.size() << endl;
}
```

**実行結果**

```PlainText
5
```

## i 番目の文字

`文字列.at(i)` のように書くと文字列の i 文字目が取得できる（添え字は 0 から始まる）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string str = "Hello";
    cout << str.at(0) << endl;
    cout << str.at(4) << endl;
}
```

**実行結果**

```PlainText
h
o
```

## 行単位での入力

`getline` 関数を使うと、空白を含む行全体を文字列として取得できる

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s, t;
    getline(cin, s);
    getline(cin, t);

    cout << "1行目" << s << endl;
    cout << "2行目" << t << endl;
}
```
